# YouTube 歌回時間軸與歌單製作標準規範 (Song Timeline SOP)

當使用者提及「依照內容做出時間軸」、「分析逐字稿歌單」、「產生歌單時間軸」、或傳入 `transcripts/` 中的 `.txt` / `.json` 逐字稿檔案時，AI 必須嚴格遵循本規範執行。

---

## 1. 執行目標與前置讀取
1. **讀取逐字稿**：
   - 優先讀取對應的 `transcripts/[YYYYMMDD]_[影片標題]_[VideoID].txt`（精簡時間戳）或 `.json`（秒數細節）。
2. **曲目與原唱辨識**：
   - 結合主播口播（報歌名）、唱出的歌詞片段與音樂知識庫，精確推敲官方日文曲名、原唱歌手（Artist）與發行年份（Release Year）。
   - **試唱片段保留**：若主播中途嘗試彈唱短曲（哪怕僅有 1 分鐘的試唱片段），一律完整收錄並標記時間軸。
   - **秒數校正**：起始時間以主播開始彈唱伴奏或歌聲切入的第一句秒數為準（精確至秒）。

---

## 2. 標準輸出雙軌格式 (對話中直接印出)

AI 在對話中回覆時，必須完整提供以下兩種格式：

### 格式 A：YouTube 留言 / 說明欄時間軸格式
```text
HH:MM:SS 01.曲名 / 原唱（發行年份）
HH:MM:SS 02.曲名 / 原唱（發行年份）
...
```
- **時間戳**：一律採用 `HH:MM:SS`（例如 `00:07:55`、`01:14:18`）。
- **曲目編號**：兩位數補零（`01.`, `02.`, ...）。
- **分隔符號**：`曲名 / 原唱`（斜線前後各空一格）。
- **年份標註**：使用全形括號 `（YYYY）`，例如 `（2022）`。

### 格式 B：songs.csv 對應資料格式 (方便貼入試算表)
```csv
Date,Title,Artist,Link
YYYY/MM/DD,曲名,原唱,https://www.youtube.com/watch?v=VIDEO_ID&t=秒數s
```
- **Date**：日期格式為 `YYYY/MM/DD`（如 `2026/06/29`）。
- **Title**：官方正式曲名。
- **Artist**：官方原唱（如 `aiko`、`HoneyWorks`、`supercell`）。
- **Link**：包含開唱秒數的播放連結（例如 `&t=475s`）。

---

## 3. 自動存檔動作 (Automatic File Saving)
在對話中回覆的同時，AI **必須自動**在 `transcripts/` 目錄下建立並寫入以下檔案備查：
- **存檔路徑**：`transcripts/[YYYYMMDD]_[影片標題]_[VideoID]_songlist.txt`
- **內容**：包含上方兩種格式的完整整合內容。
